## О презентации

Интерактивный отчёт для Совета директоров и руководства девелопера **«АТС Малиновка»**, наглядно демонстрирующий:
1. **Текущий реализованный функционал** платформы malinafix.ru (продакшн-контур).
2. **Ролевую модель (RBAC)**: Агент, Руководитель АН, Сотрудник девелопера (Штаб), Суперадминистратор, База стройматериалов, Подрядчик ИЖС.
3. **8 детальных клиентских путей (CJM)** с пошаговой фиксацией, дедупликацией и сквозной воронкой amoCRM.
4. **Субпартнёрскую сеть «Матрёшка» (60/20/20)**: подключение сетей стройматериалов и прорабов.
5. **Финансово-экономическую модель** и сравнение доходности девелопера.
6. **Дорожную карту развития** (Roadmap 2026).

## Ключевые возможности интерфейса

- **Две темы оформления:** тёмная (кинематографичный high-tech) и светлая (деловой корпоративный стиль) с переключателем ☀️ / 🌙.
- **Интерактивный финансовый калькулятор:** расчёт комиссионных пулов (Прямая фиксация 80/20 vs Матрёшка 60/20/20).
- **Интерактивный холст:** динамическая физическая сеть партнёрских связей на HTML5 Canvas.
- **Управление клавиатурой:** стрелки влево / вправо для комфортного перелистывания слайдов на совещаниях.
- **Версия для печати (A4 Ч/Б):** строгая монохромная вёрстка на 8 листов с колонтитулами для экспорта в PDF через window.print().
